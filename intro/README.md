# Intro renderer (Code → MP4 → GIF)

Apple-inspired GitHub header animation, inspired by [CyrisXD](https://github.com/CyrisXD/CyrisXD)’s particles + typewriter approach.

```bash
# from repo root
npm install
npx playwright install chromium
node intro/render.mjs
```

Outputs:

- `header.mp4`
- `header.gif` (used in the profile README)
